## 独立复核后的补充修正

1. 群体事件仍使用“毫秒 + 1000 档随机数”会撞号，使新导入校验拒绝作品。已改为 UUID，并在固定时钟/随机数环境下验证 100 名人物生成的事件唯一且可恢复；事实与快照标识也使用 UUID。
2. 快照内法则/伏笔的重复标识原先漏检。已将唯一性校验落实到每份快照，分别验证导入阶段拒绝两种重复，不让坏快照污染下次恢复。
3. 世界名称原先仅参与关键词扫描。已加入共享故事上下文，验证每个四幕请求都含当前世界名。

复核只读，未进行浏览器/真实模型验证。上述修正以新增失败用例 → 修改 → 用例通过及全量检查验证，未以复核意见替代测试。

## 使用与恢复说明

- 原审计脚本 `functional-audit-2026-11-08.cjs` 的断言记录修复前的问题行为，不适合作为当前版本的通过标准，也不应重跑覆盖历史 JSON；当前验收使用 `npm run check` 与本轮新增测试。
- 新 PDF 会增加 IndexedDB 和 JSON 体积，单文件导入上限 20 MB。旧 PDF 内容未被旧版本保存的，必须重新关联原文件；这类丢失不能由代码推测恢复。
- 对旧存档自动清理关联会产生可展开的恢复提醒，提醒可在确认后关闭；正文保留，原始导入文件不修改。
- EPUB 解压使用浏览器 [DecompressionStream 的 deflate-raw](https://developer.mozilla.org/en-US/docs/Web/API/DecompressionStream/DecompressionStream)。缺少支持、压缩损坏、加密/不支持格式或超限时明确拒绝，建议转为 TXT。
- 本轮没有新增依赖或后台付费调用。版本上传后仍应补测真实浏览器的新建→编辑→刷新→切书→备份还原，以及真实 AI 连接和内容质量。
