# Deployment and Operations Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development or superpowers:executing-plans for scoped implementation and a fresh final review. Steps use checkbox syntax for tracking.

**Goal:** Deliver a reproducible local-first application with a real production entrypoint, health probes, container configuration and release procedures.

**Architecture:** One Node process serves the built Vite frontend and optionally the existing Vertex proxy. Development keeps the Vite proxy. Cloud access remains explicitly enabled and protected by the deployment's identity gateway.

**Tech Stack:** Node >=22.18, npm workspaces, Express, native fetch, React/Vite, Docker Compose, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-11-07-delivery-design.md`

## Global Constraints

- Preserve current application features, browser storage, Google notices and existing request allowlists.
- Do not print secrets, call paid AI services, publish, commit, invent licensing or add a database/identity system.
- Work in the current directory as established by the workspace design; independent file ownership permits parallel work.
- Backend owns all `backend/` code except package metadata; root owns manifests, lockfile, containers, CI and smoke scripts; documentation task owns public Markdown and the deployment modal.

## Review Focus

- Clean checkout without credentials serves the application and reports AI disabled.
- HTML fallback never conceals unknown API paths or missing assets.
- HTTP/WS malformed input, untrusted origins and disconnects do not crash or expose secrets.
- Health probes avoid paid calls and indicate draining correctly.
- Browser manuscript backup is distinct from deployment configuration and image rollback.
