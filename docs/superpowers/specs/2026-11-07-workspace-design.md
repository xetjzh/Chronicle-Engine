# 编年创作工作台统一改造

用户授权按工程实际情况自主优化程序与 UI。本次沿用现有未提交的暖金书房外壳，在当前工作目录增量修改，保留所有已有功能与用户改动，不提交或发布。

## 方向与取舍

采用炭灰底色、暖金操作色、纸张色正文和统一的边框/圆角/焦点样式，覆盖七个主模块及全部工具弹窗。相比重写所有页面，保留组件与业务接口的渐进式统一更适合当前大量创作功能；相比仅改首页，公共设计变量可以消除内外风格割裂。成功标准是导航清晰、编辑舒适、小屏工具可达、状态反馈可信。

## 范围

- 公共设计变量与 Tailwind 色板同步；统一工作面板、表单、按钮、对话框，保留成功/警告/错误语义和写作/阅读的自选主题。
- 增加作品概览与章节导航，改善写作面板和空状态；手机提供可展开的完整导航与工具。
- 非首屏模块及图表等工具延迟加载，给出载入反馈，减少首屏资源。
- 修复存储章节复活/项目串读、导入校验、异步恢复覆盖编辑、写作重复保存、文献检索章节定位等经检查确认的问题。
- 增加必要回归测试，执行构建、静态类型检查和浏览器视觉/交互检查。真实 AI 请求依赖用户凭证，不使用付费 API 验证。

## 约束

继续使用 React、TypeScript、Vite、现有图标与组件；不引入 UI 框架。继续使用本地存储模型。避免改动 AI 生成流程与后端接口。保留阅读和写作的主题选择。可访问控件需要名称、焦点和键盘操作；减少动画偏好必须生效。
